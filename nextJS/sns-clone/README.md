## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

# Mysql terminal操作

- mysql接続

```sql
mysql -u root -p
```

- database表示

```sql
SHOW DATABASES;
```

- DB名を選択

```sql
USE DB名;
```

- デーブル検索

```sql
SHOW TABLES;
```

- 項目を表示

```sql
DESCRIBE DB名;
```
